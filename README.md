# Graph Problem Swarm Intelligence

SIS6116 code for MAX-MIN Ant System on one personalised symmetric TSP instance. The notebook runs the pipeline and writes measurements under `outputs/`. Those files are generated by a run. They are not stored in the repo.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/gopalenparasuraman/graph-problem-swarm-intelligence/blob/main/notebooks/mmas_tsp.ipynb)

## Layout

| Path | Role |
|------|------|
| `sis6116/instance.py` | Seed-4616 distance matrix |
| `sis6116/objective.py` | Tour length, including the return edge |
| `sis6116/nearest_neighbor.py` | City-0 and best-of-all-starts nearest neighbour |
| `sis6116/mmas.py` | MMAS construction, bounds, and pheromone update |
| `sis6116/experiments.py` | Fixed baseline, CSV/JSON, printed audit |
| `sis6116/validation.py` | Parameter and invariant checks |
| `sis6116/plotting.py` | Mean curve with sample-std band, and per-run overlay |
| `notebooks/mmas_tsp.ipynb` | Colab or local run of the baseline |
| `tests/` | Instance, objective, and MMAS checks |

The numeric baseline and the update order are printed at the start of each experiment (`outputs/audit.txt`). They are fixed in `baseline_settings()`.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
```

## Run

From the repository root:

```bash
pytest
python -m sis6116.experiments
```

Or open `notebooks/mmas_tsp.ipynb`. The run writes:

- `outputs/audit.txt`
- `outputs/convergence.csv`
- `outputs/runs.csv`
- `outputs/baselines.csv`
- `outputs/summary.csv`
- `outputs/summary.txt`
- `outputs/experiment.json`
- `outputs/convergence_mean_std.png`
- `outputs/convergence_overlay.png`
